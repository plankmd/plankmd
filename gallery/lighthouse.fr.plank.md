# Phare

Un grand phare à bandes rouges et blanches. Il se dresse sur un large socle
qui se rétrécit en deux marches, et se termine par une galerie, une lanterne
et un chapeau. 137 planchettes.

## Étape 1 : la première couche du socle

Le socle est fait de quatre petites tours creuses, deux par deux, montées
comme des cabanes en rondins : deux planchettes côte à côte, puis deux
planchettes en travers, posées sur leurs extrémités. Pour espacer les deux
planchettes de chaque tour, pose trois planchettes côte à côte entre elles,
puis retire-les. Les quatre tours se touchent.

```plank
```

## Étape 2 : monter le socle

Recommence deux fois : deux planchettes dans un sens, deux planchettes dans
l'autre, sur chacune des quatre tours.

```plank
```

## Étape 3 : la deuxième marche du socle

Maintenant, seulement deux tours, côte à côte, placées en travers du milieu
du socle. Chacune repose sur les deux tours du dessous. Espace les
planchettes avec trois planchettes comme avant, puis construis deux paires
de couches.

```plank
```

## Étape 4 : le fût, bande blanche

Construis le fût au milieu du socle : une seule tour, centrée au-dessus des
deux tours du dessous. Construis trois paires de couches avec des
planchettes blanches.

```plank
```

## Étape 5 : le fût, bande rouge

Construis trois paires de couches avec des planchettes rouges.

```plank
```

## Étape 6 : le fût, bande blanche

Construis trois paires de couches avec des planchettes blanches.

```plank
```

## Étape 7 : le fût, bande rouge

Construis trois paires de couches avec des planchettes rouges.

```plank
```

## Étape 8 : la galerie

Construis deux paires de couches comme le fût, mais écarte un peu les
planchettes vers l'extérieur : les deux planchettes de chaque paire sont
plus éloignées d'une épaisseur de planchette. La galerie dépasse tout autour
du fût.

```plank
```

## Étape 9 : la lanterne

Construis deux paires de couches avec des planchettes jaunes, de nouveau
dans l'alignement du fût.

```plank
```

## Étape 10 : le chapeau

Couvre la lanterne de cinq planchettes rouges côte à côte. Ajoute trois
planchettes en travers, puis une planchette par-dessus.
