# Pagode

Une pagode de style japonais à quatre étages, de plus en plus petits en
montant. Chaque étage est une rangée de petites tours creuses, avec un toit
dont les avant-toits dépassent aux deux bouts, et la pagode se termine par
une flèche. 208 planchettes.

## Étape 1 : étage 1, les murs

Construis une rangée de 4 petites tours creuses qui se touchent, comme des
cabanes en rondins : deux planchettes côte à côte, puis deux en travers,
posées sur leurs extrémités. Pour espacer les deux planchettes de chaque
tour, pose trois planchettes côte à côte entre elles, puis retire-les.
Construis deux paires de couches.

```plank
```

## Étape 2 : étage 1, le toit

Construis encore trois paires de couches avec des planchettes rouges. Sur
les deux tours des extrémités, écarte chaque paire de couches d'une
demi-largeur de planchette vers l'extérieur : ce sont les avant-toits. Le
côté intérieur de chaque tour d'extrémité reste au-dessus du mur du dessous
et retient les avant-toits. Les tours du milieu montent droit.

```plank
```

## Étape 3 : étage 2, les murs

Construis une rangée de 3 petites tours sur le toit du dessous, chacune
posée à cheval sur la jointure entre deux tours du dessous. Espace les
planchettes avec trois planchettes comme avant, puis construis deux paires
de couches.

```plank
```

## Étape 4 : étage 2, le toit
