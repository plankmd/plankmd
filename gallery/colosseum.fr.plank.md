# Amphithéâtre

Un amphithéâtre inspiré du Colisée de Rome : un anneau de deux rangs
d'arcades et d'un étage supérieur autour d'une arène de sable, avec deux
anneaux de gradins à l'intérieur. 174 planchettes. L'anneau a huit côtés,
obtenus en faisant tourner les planchettes autour du milieu. Chaque étage
est fait de piles de planchettes à plat séparées par des ouvertures, et un
anneau de planchettes posées sur les ouvertures porte l'étage suivant.

## Étape 1 : la première arcade

Construis un anneau de huit piles de cinq planchettes à plat. Commence par
la pile du fond, puis tourne chaque nouvelle pile d'un huitième de tour de
plus, toujours dans le même sens, jusqu'à fermer l'anneau. Entre deux piles,
il y a une ouverture : une arche. Pour vérifier la première, pose une
planchette en travers, à l'intérieur de l'anneau, puis retire-la.

```plank
```

## Étape 2 : les premières arches

Pose huit planchettes sur les ouvertures, chacune centrée sur une ouverture
et posée sur les deux piles qui l'entourent.

```plank
```

## Étape 3 : la deuxième arcade

Empile de nouveau huit piliers sur les arches, hauts de cinq planchettes.
Chaque pilier est au-dessus d'un pilier de la première arcade, posé sur les
extrémités des planchettes du dessous.

```plank
```

## Étape 4 : les deuxièmes arches

Pose huit planchettes sur les nouvelles ouvertures, comme avant.

```plank
```

## Étape 5 : l'étage du haut

Ajoute un étage de trois couches : un anneau de huit planchettes, un anneau
tourné d'un demi-pas pour que chaque planchette relie deux autres, puis un
dernier anneau comme le premier. Les ouvertures se referment en petites
fenêtres.

```plank
```

## Étape 6 : les gradins du haut

À l'intérieur du mur, laisse un couloir de trois planchettes de large. Pour
le mesurer, pose une planchette en travers, puis retire-la. Empile six
planchettes à six endroits autour de l'anneau.

```plank
```

## Étape 7 : les gradins du bas

Plus à l'intérieur, laisse un autre couloir de la même largeur. Empile trois
planchettes à quatre endroits, un de chaque côté.

```plank
```

## Étape 8 : l'arène

Pose six planchettes côte à côte sur le sol, au milieu : c'est le sable de
l'arène.
