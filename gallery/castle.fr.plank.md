# Château fort

Un château carré : quatre tours d'angle, des courtines crénelées, une petite
tour dans le mur du fond et une porte en encorbellement dans le mur de
devant. 234 planchettes.

## Étape 1 : la première couche des quatre tours

Chaque tour est un carré creux, monté comme une cabane en rondins : deux
planchettes côte à côte, puis deux planchettes en travers, posées sur leurs
extrémités. Pour espacer les deux planchettes d'une tour, pose trois
planchettes côte à côte entre elles, puis retire-les. Place les quatre tours à
trois longueurs de planchette les unes des autres : pose trois planchettes
bout à bout le long de l'avant et le long du côté gauche, puis retire-les.

```plank
```

## Étape 2 : monter les tours

Recommence quatre fois : deux planchettes dans un sens, deux planchettes dans
l'autre. Garde les coins bien alignés.

```plank
```

## Étape 3 : les murs des côtés

Entre les tours, construis un mur de chaque côté : trois planchettes bout à
bout, empilées sur huit rangs. Centre le mur sur les tours.

```plank
```

## Étape 4 : le mur du fond

Construis une petite tour au milieu, comme les grandes, mais haute de huit
couches seulement. Pour espacer ses planchettes, utilise trois planchettes
comme avant. Construis ensuite le mur de chaque côté, long d'une planchette et
haut de huit.

```plank
```

## Étape 5 : le mur de devant et la porte

Construis deux morceaux de mur, longs d'une planchette et hauts de cinq, avec
une longueur de planchette entre eux : pose une planchette dans l'espace pour
le mesurer, puis retire-la.

```plank
```

## Étape 6 : l'arc de la porte

Ajoute deux couches de chaque côté, chacune avancée d'une demi-largeur de
planchette dans l'ouverture. Ces planchettes sont marron. Veille à avancer le
côté gauche et le côté droit de la même façon.

```plank
```

## Étape 7 : le linteau

Termine le mur par une couche de trois planchettes : celle du milieu est le
linteau au-dessus de la porte, marron comme l'arc.

```plank
```

## Étape 8 : le haut des tours

Sur chaque grande tour, pose trois planchettes côte à côte, espacées d'une
largeur de planchette, puis recommence une fois par-dessus. Fais de même sur
la petite tour, sur une seule couche. Ce sont les créneaux.

```plank
```

## Étape 9 : les créneaux des murs

Pose des planchettes en travers sur le haut de chaque mur, espacées d'une
largeur de planchette, pour qu'elles dépassent des deux côtés. Garde la
première et la dernière planchette contre une tour.

```plank
```
