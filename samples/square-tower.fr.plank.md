# Petite tour carrée

Une tour creuse montée comme une cabane en rondins, avec un toit. 25 planchettes.

## Étape 1 : la première couche

Pose deux planchettes à plat et parallèles, pour former deux côtés d'un
carré. Pour les espacer, pose trois planchettes côte à côte entre elles, puis
retire ces trois planchettes. Pose les deux planchettes suivantes en travers
des deux premières, sur leurs extrémités.

```plank
```

## Étape 2 : monter les murs

Recommence quatre fois : deux planchettes dans un sens, deux planchettes dans
l'autre. Garde les coins bien alignés.

```plank
```

## Étape 3 : le toit

Couvre la tour avec cinq planchettes posées côte à côte.
